          スクライブ

          manage_search

          記録はScribeで探せます

          Village Portalの記録検索「Scribe」に移動して、所持品や生物の記録を探します。

          Scribeを開くopen_in_new

          Scribeでの探しかた

          1. 1loginDiscordでログイン
          2. 2tune見る範囲を選ぶ（自分の記録／トライブの生物）
          3. 3filter_alt期間・マップ・記録の種類で絞り込む
          4. 4visibility日時・マップ・内容を確認

          記録が見つからないとき

          support_agent管理者依頼Elderで管理者に相談arrow_forward

          依頼はElderで受け付けています

            ランク比較・購入

            ランクを選ぶ

            ランクが上がるほど、焚き火を囲む村人が増えていきます。

              特典をくらべる

              緑の帯は、そのランクから上で使える特典です。棒が長いほど、日数やポイントが多くなります。

              swipe横にスクロールすると、ほかのランクも見られます。

              上位のランクは下位の特典をすべて含みます。支払いはMoneta。申し込みは村のAIが受け付けます。
